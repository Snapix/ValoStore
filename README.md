# ValoStore

Cross-platform software catalogue prototype for Linux, Windows and Android.

## Run locally

No build step or environment variables are required. Open `index.html` in a browser, or run:

```bash
npx serve .
```

## Included in this test build

- Platform tabs for Linux, Windows and Android
- Search, category, license and sort filters
- Application detail dialog
- Platform-specific install commands and upstream links
- Responsive desktop and mobile layout

## Data status

This is a UI prototype with sample catalogue records. It does not yet ingest live Flathub, F-Droid or WinGet metadata. Version and update fields are illustrative. ValoStore does not host installers or APKs.

## Design

Uses a restrained light palette and app-first discovery influenced by the supplied Flathub design reference, with an independent ValoStore layout.
